系统架构与数据流
前端展示层（页面 + 路由）
首页：瀑布流 / 分类筛选 / 搜索(防抖) / 排序 / 无限加载 详情页：大图 / 标签 / 同分类推荐 收藏夹：收藏图片管理 路由：React.lazy + Suspense 代码分割
▼ fetchImages / fetchImageDetail / fetchFavorites ▼
前端架构层（基础能力）
API 层 http.ts：Axios 拦截器 / 超时 / 错误归一化 / 请求取消 状态：Context + useReducer → localStorage 持久化 → 后端同步(可降级) 类型：types/index.ts 全链路 TS 约束（strict） Hooks：useDebounce / useInView / useColumnCount
▼ GET/POST/DELETE /api/*（Vite dev 代理，生产指向线上） ▼
后端服务层（Node.js + Express，极简全栈）
routes/images：列表(分页/筛选/搜索/排序) / 详情 / 分类 routes/favorites：收藏增 / 删 / 查（RESTful） 数据：imageData 360 张确定性模拟图片（种子随机） 持久化：favoritesStore JSON 文件（重启不丢）
性能优化四件套（面试核心）
图片懒加载 + 模糊占位
IntersectionObserver 提前 240px 预载；16px 占位图 + CSS blur 渐进呈现；aspect-ratio 防 CLS
虚拟化瀑布流 MasonryGrid
只渲染可视区 ±overscan；ResizeObserver 动态测高；实测 360 条数据 DOM 常驻 ≤ 12 个、60fps
路由懒加载 + 分包
React.lazy 拆页 + manualChunks 拆第三方库；首页业务代码仅 8KB（gzip 4KB）
React.memo / useMemo / useCallback
收藏变化时未变化卡片跳过重渲染；稳定引用配合 memo 生效
